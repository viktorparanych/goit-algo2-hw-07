# Висновки щодо ефективності алгоритмів

Згідно з отриманими результатами, використання вбудованого декоратора `@lru_cache` є значно ефективнішим підходом для обчислення чисел Фібоначчі порівняно зі структурою Splay Tree. 

1. **LRU Cache** працює з хеш-таблицею словником, що забезпечує алгоритмічну складність доступу $O(1)$. Це робить час виконання стабільно низьким і майже непомітним на графіку.

2. **Splay Tree**, хоч і кешує результати, вимагає часу на пошук та вставку з амортизованою складністю $O(\log n)$. Крім того, операції балансування дерева обертання вузлів створюють додаткові накладні витрати пам'яті та процесорного часу. Це добре видно на графіку у вигляді зростання часу виконання при великих значеннях $n$.
